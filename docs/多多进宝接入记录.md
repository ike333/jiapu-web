## 二、后端实现

`backend/routers/ddk.py`：

- `GET /api/ddk/goods?keyword=&page=&page_size=` —— 搜索 `pdd.ddk.goods.search` 拉商品，再批量 `pdd.ddk.goods.promotion.url.generate` 转链，返回 `{items, total, configured}`
- `GET /api/ddk/authorize?pid=` —— **自助生成 PID 备案授权链接**（调 `pdd.ddk.rp.prom.url.generate`），避免手动拼链接；`configured=false` 时前端「好物」页会引导先备案
- `main.py` 已 `include_router(ddk.router)`

前端 `[clanId]/mall/page.tsx`（client 组件，运行时 fetch，兼容 `output:'export'`）+ Navbar「好物」入口（`ShoppingBag` 图标）；`src/lib/api.ts` 加 `fetchDdkGoods`。

## 三、签名与请求要点

- 签名：标准 MD5 —— `secret + 排序拼接参数 + secret`，**大写**
- `timestamp` 用 **Unix 秒字符串** `str(int(datetime.now().timestamp()))`；用 `yyyy-MM-dd HH:mm:ss` 会被拼多多拒（报 10001 公共参数错误:timestamp）
- urlencode 用 `quote_via=quote`（空格→`%20`），避免 `+` 被拼多多误解析为空格

## 四、坑与排错全过程

| 报错 | 根因 | 解决 |
|---|---|---|
| `10001 公共参数错误:timestamp` | 运行环境**系统时间被改到未来**（如沙箱设 2026） | `w32tm /resync` 同步 Windows 时间 |
| `50001 / 20001 非多多客` | 开放平台 `client_id` 未在多比特多多客后台绑定 | 去 jinbao.pinduoduo.com 把 client_id 绑定到多多客账号（duoId） |
| `50001 / 60001 未传入已经授权备案过的相关参数(pid/custom_parameters)` | 推广位 PID 未「授权备案」 | 调 `pdd.ddk.rp.prom.url.generate`（`p_id_list=[PID]`）生成授权链接，拼多多 APP/浏览器打开登录多多客账号授权一次即完成；**换 PID 须重新备案** |

字段名差异：

- 搜索接口：推广位字段叫 **`pid`**
- 转链接口：推广位字段叫 **`p_id`**
- 转链返回**没有 `goods_sign`**，须按 `goods_sign_list` 顺序 zip 对应

## 五、华为云生产部署清单

1. 服务器安装 `python-dotenv`：`backend/venv/bin/pip install python-dotenv`
2. `backend/.env` 写入 `PDD_CLIENT_ID / PDD_CLIENT_SECRET / PDD_PID`
3. 重启后端：`systemctl restart backend-jiapu.service`
4. 前端 `npm run build`（含 `/mall` 页）→ 按标准流程部署 out.zip
5. 生产验证：`https://chenmike.cn/chen/mall?keyword=茶叶` 应返回商品列表
